# Trama

La classificació pública de primària és per cicles. Abans d’afegir lectures o recalibrar-ne l’exigència, consulta `docs/cycle-classification.md`. Registra cada codi de fitxa a `data/cycle-classification.js`; les traduccions comparteixen assignació i les variants en tenen de pròpia. Conserva `level` i `difficulty` originals com a referència editorial i per al format inicial; la UI fa servir els helpers de `reading-levels.js`. Revisa text i preguntes, incloses ABCD, sense classificar només per llargada. Comprova cobertura i progressió amb `node tools/check-cycle-classification.mjs` i actualitza el balanç amb `node tools/catalogue-balance.mjs --write`. No alteris identificadors ni dades locals dels usuaris en canviar etiquetes.

Per ampliar preguntes amb doble format obert/ABCD, consulta `docs/question-choices.md`. Mantén la cobertura seqüencial per codi, alternatives pròpies per idioma i variant, i distractors graduats segons curs. A partir de 4t–5è les opcions han de ser plausibles i exigir lectura acurada, amb una única resposta defensable. Registra i revalida el contingut exacte al registre editorial corresponent.

Actualitza `CHANGELOG.md` amb cada canvi, encara que sigui menor. Quan publiquis una versió, sincronitza la versió i les notes a `index.html` i les traduccions a `locales/es.js`. Fes servir una versió de pedaç per als ajustos menors, com ara de 1.16 a 1.16.1.

Abans d’ampliar lectures d’un univers, consulta `docs/universes/README.md` i la guia del món corresponent. Conserva la continuïtat de personatges, llocs i il·lustracions; cada lectura ha de funcionar sense ordre obligatori. Documenta a la guia els detalls nous que es fixin i conserva les instruccions de les il·lustracions.

Després de preparar una lectura o de modificar-ne el text o les preguntes, aplicar el skill `revisio-coherencia-didactica`, instal·lat a `C:/Users/afortun8/.codex/skills/revisio-coherencia-didactica/SKILL.md`. La [font compartida i versionada](https://github.com/aaronFortuno/sentit/blob/main/skills/revisio-coherencia-didactica/SKILL.md) serveix de referència en altres entorns. Un agent independent de l'autor ha de comprovar plausibilitat, cronologia, causalitat, coneixement dels personatges, preguntes, solucionari i marques de resposta. Corregir els problemes i fer revalidar els elements afectats abans de presentar el material al docent. Cada variant o idioma requereix revisar les seves pròpies dades; no hereta l'aprovació de l'original.

Anomenar **provisional** només una versió que hagi superat aquesta revisió; abans és un **esborrany en revisió**. Registrar el codi, la versió exacta revisada, la data i el resultat final al registre editorial de la tanda, sense necessitat de publicar les iteracions internes. Un canvi editorial posterior requereix nova revisió dels elements afectats. El docent conserva l'última paraula sobre la publicació definitiva.
