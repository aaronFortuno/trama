Importa una lectura

El fitxer JSON ha d’incloure aquests tres camps.

title
El títol de la lectura.
language
El codi d’idioma, com ara ca o es.
paragraphs
Una llista amb el text de cada paràgraf.

Pots afegir preguntes, respostes i línies de resposta, tal com mostra l’exemple.

Mostra un exemple de JSON

El camp lines reserva entre 0 i 8 línies de resposta per pregunta.

Fins a 2 MB per fitxer. Les lectures importades es desen en aquest navegador.

Exporta una lectura

Descarrega el text, les preguntes, les respostes i les il·lustracions en un JSON que pots editar i tornar a importar.

Un petit espai per aprendre

Trama neix d’una necessitat senzilla: trobar una lectura i preparar una fitxa adequada per al grup. Tria una lectura del catàleg, escull les preguntes i adapta la fitxa abans d’imprimir-la.

El projecte és gratuït i segueix la filosofia Value for Value: si et resulta útil i vols donar-hi suport, pots fer un microdonatiu voluntari per Lightning. Recomanar-lo també ajuda.
