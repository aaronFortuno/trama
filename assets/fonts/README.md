# Tipografies de Trama

Els fitxers WOFF2 són còpies dels subconjunts llatí i llatí estès de Google Fonts que ja es fan servir a EdRep.

- Lora · [Projecte original](https://github.com/cyrealtype/Lora-Cyrillic) · [SIL Open Font License](lora-OFL.txt)
- Merriweather · [Projecte original](https://github.com/EbenSorkin/Merriweather4) · [SIL Open Font License](merriweather-OFL.txt)
- Andika · [SIL International](https://software.sil.org/andika/) · [SIL Open Font License](andika-OFL.txt)
- Lexend · [Projecte original](https://github.com/googlefonts/lexend) · [SIL Open Font License](lexend-OFL.txt)
- Massallera · Lletra lligada amb majúscules de pal. Fitxer reutilitzat d’EdRep amb les metadades originals.

Georgia, Arial i Courier New són tipografies del sistema.
