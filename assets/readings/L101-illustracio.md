# L101 · La ratlla del darrer punt

Narració de ficció sobre un torneig de bàdminton amb regles pactades entre els participants.

- `ratlla-punt-pista.webp` mostra les dues jugadores i la ratlla lateral.
- `ratlla-punt-acta.webp` mostra el full del marcador a la taula.

Les dues il·lustracions s’han generat per a Trama amb textura de serigrafia i es comparteixen entre les versions.
