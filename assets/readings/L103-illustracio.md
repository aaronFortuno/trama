# L103 · Un paisatge per tocar

Entrevista de ficció amb una dissenyadora de museu. L’obra, les làmines i els resultats de les proves formen part del relat.

- `paisatge-tactil-sala.webp` situa una reproducció tàctil a la sala del museu.
- `paisatge-tactil-proves.webp` compara els dos prototips a la taula de treball.

Les dues il·lustracions s’han generat per a Trama i es comparteixen entre les dues versions.
